# 个人工作与生活管理系统 — 设计文档

- 日期：2026-09-29
- 状态：需求 + 页面设计评审通过，待实现
- 工作代号：LifeOS（正式名称可随时另起，不影响开发）
- 使用方式：纯个人本地使用，单用户，无登录

## 1. 项目目标

一款 Windows 桌面应用，整合个人工作与生活管理：今日计划、日程、工作（自我学习 / 开发 / 设计灵感）、生活（健身 / 饮食 / 游戏娱乐）、设置与数据管理。所有数据本地持久化，重启不丢失。

## 2. 非目标（第一版不做）

- 不做登录、多用户
- 不做云端同步、多端、手机端
- 除"网站风格模仿"功能外不做任何联网功能（风格模仿是已确认的联网例外）
- 不做对外发布/分享功能

## 3. 技术架构

| 层 | 选型 |
|---|---|
| 桌面壳 | Electron |
| 前端 | React + TypeScript + Vite + Tailwind CSS + shadcn/ui |
| 状态管理 | Zustand |
| 数据库 | SQLite（better-sqlite3，WAL 模式） |
| 打包 | electron-builder → Windows exe |

**主进程职责**：窗口管理（记住位置尺寸、可选开机自启）、SQLite 读写、图片文件存取、系统通知、网站抓取（风格模仿）、备份调度。

**进程边界**：渲染进程不直接访问数据库；一切读写经 IPC 调用主进程完成，保证事务完整性。

**数据目录**：`%APPDATA%\LifeOS\`（`C:\Users\xinru\AppData\Roaming\LifeOS\`），内含 `app.db`、`images/`、`backups/`。升级应用不影响数据。

## 5. 界面骨架与页面结构

```
┌──────────────────────────────────────────────┐
│  常驻长期任务时间轴（X 轴 = 日期，横向展开）     │
├──────────┬───────────────────────────────────┤
│ 侧边导航  │                                   │
│ 🏠 今天   │        主内容区                    │
│ 📅 日程   │        （当前模块）                 │
│ 💼 工作   │                                   │
│ 🏖️ 生活   │                                   │
│ ⚙️ 设置   │                                   │
└──────────┴───────────────────────────────────┘
```

- **常驻时间轴**：任何模块下都在顶部。
  - 紧凑模式（默认）：细轴（约 40px），显示日期刻度、今日游标、长期任务的小色块标记
  - 展开模式（评审选定方案 C）：点击后轴区加高至约 110px，色块变大；**点击色块弹出详情浮层**（任务名、起止日期、剩余天数、跳转对应模块按钮）
- **默认首页**：「今天」页
- 侧边导航分组：今天 / 日程规划 / 工作（自我学习·开发·设计灵感）/ 生活（健身·饮食·游戏娱乐）/ 设置和数据

### 5.1 「今天」页（评审选定方案 A：左右分栏）

- **左侧（约 55%）今日待办清单**：手动添加（标题+优先级）、打勾完成；当日日程事件自动汇入（带来源标记，不可编辑日程字段）；待办可"转为日程"
- **右侧（约 45%）今日卡片竖排**：🏋️ 今天的训练（来自训练计划）、🍚 三餐打卡状态、📖 今日学习项+已学时长、💻 进行中项目任务摘要；点击卡片跳转对应模块
- 设计灵感、游戏娱乐无今日卡片

### 5.2 日程规划

- **周视图（默认）**：七列日格 + 左侧时间刻度；事件按模块色显示色块；"今天"列强调色描边；待办可拖入格子转为日程
- **月视图**：月历格，每天最多 3 条事件，超出折叠「+N」；点某天跳该日周视图
- 全天事件显示为通栏色条

### 5.3 开发模块

- 模块内三视图切换：**项目 / 代码片段 / 技术笔记**
- **项目列表**：卡片（名称、状态灯：计划中黄/开发中绿/已完成灰、简介、任务进度条、本周计时、未修 Bug 数）
- **项目详情**页签：看板 | Bug | 计时统计
  - 看板三列拖拽：待办 → 进行中 → 已完成；卡片带优先级、截止日；右上角常驻当前计时器（任务名、时长、停止按钮）；卡片菜单可"标记为长期任务"
  - Bug 页签：列表（现象、优先级、状态流转）
  - 计时统计：按项目/任务汇总时长
- 代码片段库：列表+标签筛选+关键词搜索
- 技术笔记：列表，可关联项目

### 5.4 设计灵感模块

- **瀑布流（默认）**：图片卡（缩略图、⭐精选角标、🔗来源、所属画板）与文字卡（内容+标签）混排
- 顶部筛选：全部 | ⭐精选 | 🗂画板 | 标签 | 搜索
- **「＋捕获」**：弹窗三合一（贴图 / 写文字 / 贴链接）
- **画板视图**：画板卡片（封面=画板内最新图片、灵感条数），点进看该画板瀑布流

### 5.5 自我学习

- 左侧学习项列表：名称、类型（📖书/🎬课程/🧠技能）、状态、进度条（done_units/total_units）、笔记数、"标记长期任务"入口
- 右侧统计：今日/本周时长、连续学习🔥、本周每日时长柱状图
- 学习项详情：进度编辑 + 笔记增删改 + 学习计时（计入统计）

### 5.6 健身

- 三栏：①今日训练（来自训练计划：动作+组数×次数+重量，「完成打卡」按钮）②体重体脂趋势线 ③本周统计（次数/总容量/连续打卡）
- 打卡记录：日期 + 内容（JSON：动作/重量/组数）

### 5.7 饮食

- 三餐卡片（早/中/晚+加餐）：已记录显示食物+热量，未记录虚线占位
- 饮食计划横条：未来某天/某周的餐食安排
- 今日摄入面板：热量进度条（vs 参考值）+ 三大营养素合计

### 5.8 游戏娱乐

- 三页签：游玩记录 | 愿望单 | 影视书
- 游玩记录按游戏聚合：总时长、最近游玩时间；记录一次游玩 = 游戏名+时长
- 影视书：类型、状态、五星评分、短评

## 6. 模块功能详单（需求评审版）

### 6.1 日程规划

- 多视图日历：周视图 + 月视图
- 事件管理：标题、开始/结束时间、地点、备注
- 重复事件：按天/周/月重复，可设重复截止日期
- 事件提醒：到期前系统通知，提前量可调
- 互通：日程事件自动出现在「今天」页当日待办；待办可"转为日程"

### 6.2 自我学习

- 学习清单：条目（书/课程/技能），状态：未开始/学习中/已完成
- 进度追踪：总量目标（如 30 章）、当前进度、百分比
- 学习笔记：每学习项下挂笔记
- 学习统计：每日/每周时长、连续学习天数

### 6.3 开发

- 项目列表：状态（计划中/开发中/暂停/已完成）、简介
- 任务看板：项目内三列拖拽（待办/进行中/已完成）
- Bug 记录：现象、优先级、状态（未修/修复中/已修复）
- 代码片段库：标题、代码、语言、标签、搜索
- 技术笔记：标题、正文、可关联项目
- 开发计时：任务手动开始/停止，按项目汇总

### 6.4 设计灵感记录

- 灵感速记：文字 + 标签分类
- 图片收集：拖入/粘贴，瀑布流
- 来源链接：附来源 URL
- 精选标记：标星筛选
- 灵感画板：多条灵感归画板
- （不做状态流转）

### 6.5 健身

- 训练计划：自定义计划（如推/拉/腿分化），安排每天练什么
- 训练打卡：动作、重量、组数历史
- 身体数据：体重、体脂率曲线
- 健身统计：周次数、总容量
- （不做动作库）

### 6.6 饮食

- 三餐打卡：记录每餐内容
- 热量/营养追踪：热量、蛋白质/碳水/脂肪、每日合计
- 饮食计划：提前规划某天/某周
- （不做：饮食目标、食物库、饮水记录）

### 6.7 游戏娱乐

- 游玩记录：日期、时长，按游戏聚合计总时长
- 愿望单：游戏 + 优先级
- 影视书：类型、状态、评分、短评
- （不做游戏库）

### 6.8 设置和数据

- 外观设置：深色/浅色、主题色；**网站风格模仿**——粘贴网址，抓取页面提取配色/字体生成主题，失败时手动选色兜底
- 时间轴设置：显示范围（未来 7/30/90 天）、是否显示已完成长期任务
- 提醒设置：声音开关、提前分钟数
- 数据导出：数据库文件 + 图片打包
- 数据导入：从导出包恢复

### 6.9 常驻长期任务时间轴（全局特殊功能）

- 仅 ≥2 天的长期任务上轴；无持续时间的日常小事不上轴
- 来源双通道：各模块事项标记日期区间 / 独立创建（不隶属模块）
- 常驻顶部；紧凑模式（细轴+今日游标+色块标记）⇄ 展开模式（轴加高，点色块看详情浮层）
- 色块颜色 = 来源模块色

## 7. 数据模型

所有表含 `id`（自增主键）、`created_at`、`updated_at` 字段（下文从略）。

### 7.1 核心三件套

| 表 | 关键字段 |
|---|---|
| `tasks` | `title`, `done`, `priority`(low/mid/high), `done_at`, `date`(归属日), `source_module`(可空: event/long_task/learn_item/dev_task…), `source_id`(可空) |
| `events` | `title`, `start_at`, `end_at`, `location`, `note`, `repeat_type`(none/daily/weekly/monthly), `repeat_interval`, `repeat_until`, `remind_minutes` |
| `long_tasks` | `title`, `start_date`, `end_date`, `color`, `source_module`(可空), `source_id`(可空) |

- 日程事件展开为具体日期的待办展示时，`tasks.source_module='event'`。
- 长期任务在其日期区间内的每一天显示于时间轴。

### 7.2 自我学习

- `learn_items`: `title`, `type`(book/course/skill), `status`(not_started/learning/done), `total_units`, `done_units`, `start_date`, `end_date`(可空，供长期任务联动)
- `learn_notes`: `item_id` → learn_items, `content`
- `learn_sessions`: `item_id`, `date`, `minutes`

### 7.3 开发

- `projects`: `name`, `status`(planned/in_progress/paused/done), `description`, `start_date`, `end_date`(可空，供长期任务联动)
- `dev_tasks`: `project_id`, `title`, `column`(todo/doing/done), `position`(列内排序), `start_date`, `due_date`(可空)
- `bugs`: `project_id`, `title`, `description`, `priority`(low/mid/high), `status`(open/fixing/fixed)
- `snippets`: `title`, `code`, `language`, `tags`(JSON 数组)
- `tech_notes`: `title`, `content`, `project_id`(可空)
- `dev_sessions`: `task_id`, `started_at`, `ended_at`, `minutes`

### 7.4 设计灵感

- `inspiration_boards`: `name`
- `inspirations`: `board_id`(可空), `text`, `image_path`(可空), `source_url`(可空), `starred`, `tags`(JSON 数组)

### 7.5 健身

- `workout_plans`: `name`, `schedule`(JSON，如 `{"周一":"胸","周二":"背",…}`)
- `workout_logs`: `plan_id`(可空), `date`, `content`(JSON，动作/重量/组数数组)
- `body_metrics`: `date`, `weight`, `body_fat`(可空)

### 7.6 饮食

- `meals`: `date`, `type`(breakfast/lunch/dinner/snack), `items`(JSON，[{name, calories, protein, carbs, fat}])
- `meal_plans`: `date`, `type`, `content`(文本/JSON)

### 7.7 游戏娱乐

- `plays`: `game`, `date`, `minutes`
- `wishlist`: `name`, `platform`, `priority`
- `media`: `title`, `type`(movie/series/book), `status`, `rating`, `comment`, `date`

### 7.8 系统

- `settings`: `key`, `value`
- `themes`: `name`, `source_url`(可空), `colors`(JSON：主色/强调色/背景/文字等), `is_active`

## 8. 关键交互流程

1. **日程 ⇄ 待办**：日程事件自动出现在「今天」页当日待办；待办点"转为日程"补时间后写入 `events` 并进入日历
2. **长期任务上轴**：模块事项设起止日期后可在时间轴"标记为长期任务"；也可在时间轴直接创建独立任务；点击时间轴色块弹详情浮层
3. **网站风格模仿**：设置 → 外观 → 粘贴网址 → 主进程抓取页面 → 提取配色/字体 → 主题预览 → 确认应用；失败（超时/403/解析失败）提示并允许手动选色
4. **事件提醒**：主进程轮询未来 24h 事件，到点前 `remind_minutes` 分钟发系统通知，点击唤起应用
5. **看板拖拽**：任务卡片跨列拖动更新 `column` 与 `position`；进行中卡片可开始计时

## 9. 数据安全与错误处理

- 事务：多步写入全部在 SQLite 事务中，失败回滚
- 启动校验：检查 `app.db` 完整性（quick_check），损坏时从最近备份恢复并提示
- 滚动备份：启动时复制数据库到 `backups/`，保留最近 10 份
- 图片管理：灵感图片写入 `images/`（UUID 命名），删除灵感同步删文件
- 导入恢复：导入前自动备份当前库，失败可回退

## 10. 测试策略

- 数据层与工具函数：Vitest 单元测试（CRUD、日期展开、统计聚合、重复事件展开）
- UI：关键流程手动验收清单
- 不强制 E2E 自动化
