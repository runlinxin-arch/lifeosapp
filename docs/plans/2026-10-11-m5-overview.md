## 范围

### 1. 主题系统（外观）
- 扩展 `Settings`：`theme.mode`（`dark | light`）、`theme.accent`（十六进制主题色）、`theme.custom`（网站风格模仿生成的整组覆盖色，`ThemePalette | null`）。
- 渲染端通过 CSS 变量即时生效：浅色模式切换整套色板、主题色覆盖 `--accent`、自定义主题覆盖全部 6 个变量。
- 默认：`mode='dark'`、`accent='#7c8cff'`、`custom=null`。

### 2. 设置页 UI
- 新建 `SettingsPage.tsx`，四区块：外观 / 提醒 / 时间轴 / 数据。
- 启用侧边栏「设置和数据」入口（去掉 `disabled`），`App.tsx` 加 `settings` 路由。

### 3. 网站风格模仿
- 主进程 `theme:fetchStyle(url)`：带超时抓取 → 提取 `<meta name="theme-color">` + HTML 内联 `style` 的 hex/rgb 色 → 按频率排序，返回候选配色；失败返回原因。
- 渲染端：粘贴网址 → 抓取 → 预览（临时变量）→ 确认应用（写入 `theme.custom`）；失败提示原因并允许手动选色兜底。

### 4. 数据导出 / 导入
- 导出：`app.db` + `images/` 用 node-tar（已随 electron-builder 在 `node_modules`）打包成单个 `LifeOS-backup-<时间戳>.tar.gz`，`dialog.showSaveDialog` 选目标。
- 导入：`dialog.showOpenDialog` 选包 → 先备份当前库 → 解压覆盖 `app.db` + `images/` → 校验成功后 `app.relaunch()`；失败回滚到备份。

### 5. 打包
- `electron-builder` 生成 Windows NSIS 安装包，验证可安装/运行/卸载（PRD 8.9）。

### 6. 回写
- 设计文档 §7 回写 M2–M4 累计 schema 偏差；README / DEVELOPMENT-PLAN 里程碑状态更新为 M5 完成。
