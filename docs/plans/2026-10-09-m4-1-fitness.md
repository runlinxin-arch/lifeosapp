# M4-1 健身模块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付「健身」模块：训练计划可编排一周安排、按动作/重量/组数打卡、体重体脂记录与趋势曲线、本周统计（训练次数 / 总容量 / 连续打卡）。对应 PRD 4.5 与 8.7.1。

**Architecture:** 延续 M1–M3 的分层。新增三张表以迁移 v6 落地；一周安排与打卡动作都以 JSON 列存储，读写统一走「解析 → 校验 → 序列化」的纯函数（坏数据回退空值，不炸界面）；曲线坐标计算与统计口径全部是纯函数，界面不重复实现。

**Tech Stack:** Electron 44 + electron-vite + React 18 + TypeScript + Tailwind + Zustand + `node:sqlite` + Vitest

## Global Constraints

- 数据目录 `%APPDATA%\LifeOS\`；渲染进程禁止直接访问数据库与文件系统
- 多步写入必须包在事务中，失败回滚
- 深色色板：底色 `#1e1f24`、卡片 `#26272e`、描边 `#3a3b45`、强调 `#7c8cff`、正文 `#e4e4e7`、次要 `#8b8d98`；**健身模块色红 `#e74c3c`**
- 日期 `YYYY-MM-DD`；**`schedule` 的键一律用 ISO 星期数字 `"1"`–`"7"`**（1=周一），展示层再映射为「周一」
- **不得修改已发布的 v1–v5 迁移**，本次新增 v6
- 提交前固定顺序：`npm test` → `npm run typecheck` → commit
- 起点基线：32 个测试文件 / 528 用例全绿，`typecheck` 0 错误
- 复用：`assertNonEmpty` / `assertDateStr` / `assertDateRange`、`formatIpcError`、`LatestGuard`、`parseTags` 的容错思路、`dates.ts`、`layout.ts` 的 `weekDays`

## 与设计文档的偏差（需在 M5 回写）

1. `workout_plans.schedule` 的键由中文（`{"周一":"胸"}`）改为 ISO 数字（`{"1":"胸"}`）——避免用中文字符串做逻辑判断
2. `workout_logs.plan_id` 采用 `ON DELETE SET NULL`——删除计划后历史打卡保留
3. `body_metrics.date` 加 `UNIQUE` 约束——每天一条，写入走 upsert

  updated_at: string
}

  id: number
  plan_id: number | null
  date: string
  content: WorkoutItem[]
  created_at: string
  updated_at: string
}

export interface BodyMetric {
  id: number
  date: string
  weight: number
  body_fat: number | null
  created_at: string
  updated_at: string
}

  name: string
  schedule?: Record<string, string>

export interface WorkoutLogInput {
  date: string

  content?: WorkoutItem[]

### Task 2: 健身 JSON 列与统计纯函数（TDD）

**Files:**
- Create: `src/shared/fitnessContent.ts`（JSON 列的解析 / 校验 / 序列化）
- Create: `src/shared/fitnessStats.ts`（统计与曲线坐标）
- Test: `tests/fitnessContent.test.ts`、`tests/fitnessStats.test.ts`

**Interfaces:**
- Produces（`@shared/fitnessContent`）：
  - `parseSchedule(raw: string): Record<string, string>`
  - `normalizeSchedule(input: Record<string, string> | undefined): Record<string, string>`
  - `scheduleToJson(schedule: Record<string, string>): string`
  - `parseWorkoutContent(raw: string): WorkoutItem[]`
  - `normalizeWorkoutContent(input: WorkoutItem[] | undefined): WorkoutItem[]`
  - `workoutContentToJson(items: WorkoutItem[]): string`
  - `WEEKDAY_LABELS: Record<string, string>`（`"1" → "周一"` … `"7" → "周日"`）
- Produces（`@shared/fitnessStats`）：
  - `isoWeekday(date: string): number`（1=周一…7=周日）
  - `planForDate(schedule: Record<string, string>, date: string): string | null`
  - `itemVolume(item: WorkoutItem): number`
  - `totalVolume(logs: { date: string; content: WorkoutItem[] }[], from: string, to: string): number`
  - `workoutCount(logs: { date: string }[], from: string, to: string): number`
  - `workoutStreak(logs: { date: string }[], today: string): number`
  - `toSvgPoints(points: { date: string; value: number }[], width: number, height: number, pad?: number): { x: number; y: number }[]`
  - `linePath(pts: { x: number; y: number }[]): string`
  - `latestMetric<T extends { date: string }>(rows: T[]): T | null`

**锁定的行为契约：**

*JSON 列*
1. `parseSchedule`：坏 JSON / 非对象 → `{}`；值非字符串或去空白后为空 → 丢弃该键；键不在 `"1"–"7"` → 丢弃
2. `normalizeSchedule`：只保留 `"1"`–`"7"`，值去首尾空白，空值即视为不练（保留键但值为 `""` 会被丢弃）
3. `parseWorkoutContent`：坏 JSON / 非数组 → `[]`；逐项校验，**任一项不合法就丢弃该项**（不整体失败）
4. `normalizeWorkoutContent`：`name` 去空白且非空、`weight` 取 ≥0 的有限数（否则 0）、`sets`/`reps` 取 ≥1 的整数（否则 1）

*统计*
5. `itemVolume = weight × sets × reps`（自重动作 weight=0 → 容量 0，但**训练次数照常计**）
6. `totalVolume` / `workoutCount` 含端点按 `date` 过滤
7. `workoutStreak`：今天有打卡则从今天往前连数；今天没有但昨天有则从昨天往前；否则 0（与 `learnStats.streakDays` 同语义）
8. `planForDate`：查 `schedule[String(isoWeekday(date))]`，无则 `null`
9. `toSvgPoints`：
   - 空数组 → `[]`
   - 单点 → 水平居中（`x = width/2`），y 按值域映射
   - 所有值相同 → 全部落在垂直中点（**避免除零**）
   - x 按数组下标均匀分布；y 需**反向映射**（SVG 的 y 向下），值越大 y 越小
   - 结果夹在 `[pad, width-pad] × [pad, height-pad]`
10. `linePath`：0 点 → `''`；1 点 → `M x y`；多点 → `M x0 y0 L x1 y1 …`
