## 三、开源工程标准化 + 上线

| 项 | 内容 | 提交 |
|---|---|---|
| LICENSE | MIT 许可证 | `15a3a76` |
| CI | `.github/workflows/ci.yml`：push/PR 自动 test → typecheck → build | `15a3a76`、`025b2d5` |
| Release | `.github/workflows/release.yml`：推 `v*` 标签自动打包发版 | `15a3a76`、`025b2d5`、`7e2383b`、`d479b97` |
| 文档 | README 徽章 + 下载入口、CHANGELOG.md、package.json 元信息 | `15a3a76` |

**上线结果**：代码与 8 个标签推送到 GitHub；`v0.1.0` 由 **CI（`github-actions[bot]`）自动发布**，附安装包 `LifeOS.Setup.0.1.0.exe`。

**过程中解决的 4 个拦路问题**：
1. GitHub 令牌缺 `workflow` 权限（推送 CI 脚本必需）→ 设备码授权补上
2. `actions/checkout@v4`、`setup-node@v4` 目标 Node 20 已弃用 → 升到 **v5**
3. electron-builder 检测到 tag 后自动 publish 报错 → 加 `--publish never`
4. `GITHUB_TOKEN` 默认只读，创建 Release 报 403 → 工作流声明 `permissions: contents: write`
